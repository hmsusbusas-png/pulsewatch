# Security

Поддерживается текущая версия 1.x. Об уязвимости сообщайте через вкладку
Security → Report a vulnerability в репозитории GitHub. Не публикуйте токены,
пароли, содержимое .env и персональные данные в публичном issue.

Пароли хешируются bcrypt с cost 12. JWT живёт не более 15 минут; refresh и
одноразовые коды хранятся хешами. Заголовки мониторов, настройки каналов и
письма очереди шифруются Fernet. Ротация ключей описана в backend/README.md.

Публичная статус-страница раскрывает только выбранные сайты и публичные
заметки. Выгрузка данных требует прав владельца и соответствующего тарифа.
Удаление аккаунта каскадно удаляет его данные. Дамп БД и ключи шифрования
нельзя публиковать; резервные копии должны иметь такой же контроль доступа.
